Responses received to the RTI audit, first-pass coded. Built . Refreshes every two days from the Drive folder.
Coding is single-pass and provisional until double-coded.

Filed and answered, by state

FiledAnswered

Filed counts come from receipts in the Filed_RTI folder; a state with receipts but no responses still shows.

What happened

Full = information supplied. Partial = some supplied. Fee pending = release on payment. Returned = bounced with nothing. Denied = refused or deflected. Transferred = handed to another office.

How detailed was what came back

Format A = one row per RTI application the office received. Format B = monthly or category counts. Format C = a few period totals. Prose only = no numbers. Nothing = nothing usable.

Days from filing to the PIO's reply

Date on the PIO's document minus the portal filing date. For postal replies this understates the days until we actually received it.
